# Combat Lab fights
#
# Each fight below becomes a start scenario on the game's New Pilot screen,
# named "Combat Lab: <fight name>". Pick one, take off, and the duel begins:
# your ship and the enemy start facing each other, and the moment either one
# is disabled or destroyed, both are repaired, rearmed, and put back. The
# score shows in the message log.
#
# Both ships fly their stock outfits. Copy ship names from the list at the
# bottom of this file (the class is in parentheses).
#
#   fight "<name>"
#   	player "<ship model>"
#   	enemy "<ship model>"
#   	distance <starting distance between them>    (optional, default 1500)
#
# After editing, rebuild the plugin and check it:
#   eesky/combat-lab/build.py && eesky/validate.sh
# Then copy it to the Steam Deck:
#   rsync -av --delete eesky/plugins/eesky-combat-lab deck@steamdeck:.local/share/endless-sky/plugins/
